# Kivo Studio Production Skill

English-language guidance for films and short dramas made with **[Kivo Studio](https://kivst.com) MCP**: multi-agent collaboration, consistent scenes, draft sampling, authorized production upgrades, audiovisual/lip-sync QC, subtitles and delivery.

Derived from recent team experience and checked against live connector schemas and a read-only catalog on 2026-11-08 (Asia/Shanghai). Independent community guidance, not official documentation or a quality guarantee.

## Quick start

1. Connect the supported Kivo/kivst MCP connector through your host's trusted user authentication workflow.
2. Read [SKILL.md](SKILL.md) and [MCP_CONFIG.md](MCP_CONFIG.md). For an independent client, obtain official endpoint/auth instructions first; no invented portable config is supplied here.
3. Discover tools, read catalog/project context, agree budget and acceptance gates, assign artifact owners.
4. Inspect a small representative draft sequence, lock candidates, then quote → authorize → create → bounded polling → private download.
5. Re-edit upgraded plates and inspect the assembled film, not just metadata.

File-based skill hosts should keep SKILL.md and companion files together in their supported skill folder. YAML frontmatter supplies name and trigger description. A host storing only title/description/body must also preserve access to the companion integration guidance; relative links alone are not self-contained. This package performs no global installation.

## Boundaries and maintenance

- Paid work needs authorized access/credits and user-approved scope; creative approval alone does not authorize spending or sharing.
- Host discovery wrappers are not portable server methods. Public standalone endpoint/auth setup remains unverified.
- Refresh tools, prices, capacity and draft TTL at runtime. Separate input-schema facts, tool-description semantics, live catalog observations and production practice.
- 24 fps/48 kHz are project conventions. References, metadata checks and higher resolution cannot guarantee continuity, lip sync or sound quality.
- Local QC requires ffprobe/FFmpeg and an editor; ASR is optional and does not prove alignment.
- Keep IDs, scripts, private assets, receipts, emails, keys and signed links outside releases. Redact contributions/issues.
- Update documented practice without running paid experiments unless authorized.
